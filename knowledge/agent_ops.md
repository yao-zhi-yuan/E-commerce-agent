# Agent 运行手册

Agent 任务采用至少一次消费语义。消费者必须先确认任务状态，只有完成业务处理和状态持久化后才确认消息。重复消息不能重复产生外部副作用。

每个模型调用和工具调用都必须有独立超时，整个任务还需要更大的总超时。重试只覆盖可恢复错误，并使用有限次数的指数退避；参数错误和权限错误不应盲目重试。

Agent Loop 必须同时限制最大迭代次数和重复动作次数。连续产生相同工具名与参数通常意味着模型进入死循环，应立即终止并保留检查点。

SSE 事件需要稳定的事件类型、递增序号和可回放事件 ID。客户端断线后使用 Last-Event-ID 继续消费，不能要求任务重新执行。
